# pkr-sota Task Orchestration Guide

This document outlines the wave-based parallel execution strategy for the `pkr-sota` project.

## Execution Strategy

To achieve zero merge conflicts across 4 parallel AI agents, tasks are grouped into **Waves**.
- Agents can only work on tasks within the current Wave.
- An agent must be provided the prompt generated by `generate-agent-prompt.sh <TASK_ID>`.
- Agents must strictly adhere to the "Exclusive File Paths" listed in their task.
- No agent is allowed to modify `Cargo.toml` at the workspace root or the `pkr-contracts` crate (after Wave 0).

## Wave Dependencies

Wave 0 (Foundation)
  └── W0-T1 (Contracts)

Wave 1 (Primitives)
  ├── W1-T1 (Card Primitives)       [Depends: W0-T1]

  ├── W1-T3 (Compact CFR Table)     [Depends: W0-T1]

Wave 2 (Algorithms)

## How to Run

1. Ensure you are on the `main` branch with a clean working tree.
2. Run the prompt generator: `./generate-agent-prompt.sh W1-T1`
3. Feed the output to your AI agent (Claude, GPT-4, etc.).
4. The agent will return a bash script. Save it and run it.
5. The script will automatically create a worktree, implement the code, run tests, and open a PR.
6. Merge the PR into `main`.
7. Repeat for all tasks in the current Wave.
8. Once all tasks in a Wave are merged, proceed to the next Wave.
